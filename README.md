# Downloads-Archive

Every original Helbreath download used by this project, kept exactly as downloaded for safe keeping.

## Contents

Not tied to one version, so the name has no version prefix.

| Folder | What |
|---|---|
| `retail_2001/` | Listing of the 2001 retail CD. The CD image itself, `HelbreatH.iso` (361,857,024 bytes, from archive.org), is a release asset. |
| `patch_v223/` | `patch_v223.zip`, the official 2.23 patch (Wayback copy of helbreathusa.com). |
| `sf_203/` | `2.03_hbSource_Source.zip`, the 2.03 source from SourceForge (2004). |
| `forum_gate220/` | The 2.20 gate server archive from the forum (`gate220.bin` is the same file under its download name). |
| `forum_clients/`, `forum_other/` | Client source and client bundles from community forums. |
| `outpost/` | 2.20 server source zip and 3.51 config / SQL dumps from Outpost. |

Release `originals` holds the files over 100 MB: `HelbreatH.iso` and `helbreath-v3.82.zip` (a later community 3.82 archive,
used only as a reference for config versions).

Where each came from, with URLs, is in [2.20-Documentation](https://github.com/Original-Helbreath/2.20-Documentation) `research/sources.md`.
Nothing here is ever modified.

This repo is a plain archive with a single `master` branch, unlike the versioned repos.

## Project

Part of [Original Helbreath](https://github.com/Original-Helbreath): keeping the original 1999-2005 Siementech Helbreath alive.
Issues are tracked on the [project board](https://github.com/orgs/Original-Helbreath/projects/1). The analysis behind everything is in
[2.20-Documentation](https://github.com/Original-Helbreath/2.20-Documentation).
