# Downloads-Archive

Every original Helbreath download used by this project, kept exactly as downloaded for safe keeping.

## Contents

Not tied to one version, so the name has no version prefix.

| Folder | What |
|---|---|
| `retail_2001/` | Listing of the 2001 retail CD. The CD image itself, `HelbreatH.iso` (361,857,024 bytes, from archive.org), is a release asset. |
| `patch_v223/` | `patch_v223.zip`, the official 2.23 patch (Wayback copy of helbreathusa.com). |
| `sf_203/` | `2.03_hbSource_Source.zip`, the 2.03 source from SourceForge (2004). |
| `forum_gate220/` | The 2.20 gate server archive from the forum (`gate220.bin` is the same file under its download name). |
| `forum_clients/`, `forum_other/` | Client source and client bundles from community forums. |
| `outpost/` | 2.20 server source zip and 3.51 config / SQL dumps from Outpost. |
| `wayback_2026/` | Wayback Machine captures (2026-10-27) of helbreath.com, helbreathusa.com and test.helbreathusa.com, by host and path: the 2002 Korean and Japanese launchers, USA patches 3.0-3.81, and the utilities the official sites offered. `patch_v223.zip` was identical to `patch_v223/` and is not repeated. |
